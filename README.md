# Weather-Forecast
# 🌦️ Weather Dashboard

A responsive weather dashboard web app that provides current weather conditions and a 5-day forecast for any city in Nigeria using the OpenWeatherMap API. Built with HTML, CSS, and JavaScript, the app features a modern dark UI and intuitive card-based layout for displaying weather details.

---

## 🚀 Features

- 🔍 **City Search**: Enter any Nigerian city name to get weather details.
- 🌡️ **Current Weather**: See real-time temperature, humidity, and weather conditions.
- 📅 **5-Day Forecast**: View daily forecasts with weather icons and details.
- 🎨 **Dark Mode UI**: Sleek, black-themed design with soft shadows and hover animations.
- 📱 **Responsive Layout**: Works beautifully across desktops, tablets, and mobile devices.
